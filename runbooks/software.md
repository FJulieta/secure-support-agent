
# Runbook: Instalación de software corporativo

## Objetivo
Gestionar solicitudes de instalación y actualización
de software en equipos corporativos de forma segura.

## Diagnóstico
1. Identificar el nombre y la versión del software solicitado.
2. Verificar si el software figura en el catálogo corporativo autorizado.
3. Comprobar la compatibilidad con el sistema operativo.
4. Revisar si el usuario dispone de los permisos necesarios.
5. Verificar si existe una instalación previa del software.

## Resolución

### Software autorizado
- Confirmar que el software está aprobado por la organización.
- Descargar el instalador desde el repositorio corporativo oficial.
- Seguir el procedimiento de instalación documentado.
- Verificar que la aplicación funcione correctamente.
- Registrar la instalación en el sistema de gestión de activos.

### Software no autorizado
- No instalar el software.
- Solicitar una evaluación al equipo de Seguridad de la Información.
- Esperar la aprobación antes de continuar.

### Error durante la instalación
- Revisar los mensajes de error.
- Verificar la compatibilidad del sistema.
- Comprobar los permisos necesarios.
- Escalar si el problema persiste.

## Política de seguridad
- No descargar software desde fuentes no autorizadas.
- No solicitar contraseñas de administrador.
- No desactivar antivirus, EDR ni otros controles de seguridad.
- No otorgar privilegios elevados sin autorización.
- No ejecutar instaladores de procedencia desconocida.

## Escalamiento
Escalar al equipo correspondiente cuando:
- El software no está incluido en el catálogo autorizado.
- Se requieren permisos administrativos no disponibles.
- Se detecta un instalador sospechoso.
- La instalación falla después del diagnóstico.

Las solicitudes de software no autorizado deben
derivarse al equipo de Seguridad de la Información.
