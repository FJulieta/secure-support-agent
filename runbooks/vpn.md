# Runbook: Problemas de conexión VPN

## Diagnóstico
1. Verificar que el usuario tenga conexión a Internet.
2. Comprobar que el servicio VPN esté disponible.
3. Revisar los registros de autenticación.

## Resolución
Si el problema está relacionado con MFA,
derivar al equipo de Identity Management.

## Escalamiento
Si el problema persiste después de las verificaciones,
escalar al equipo de soporte L2.
